Aplicación reutilizable Porter Matrix Pro, diseñada para sesiones ejecutivas de mentoría y consultoría estratégica.

Key Capabilities Included:
Entrada de Datos & Presets: Carga perfiles precargados para SaaS B2B, Cafeterías de Especialidad, Retail de Supermercados y Fintech, o completa campos personalizados para cualquier empresa.

Generación con IA Incorporada: Incluye un botón para autogenerar el análisis de las 5 fuerzas usando Gemini API (gemini-3-flash-preview) en tiempo real.

Calibración Cualitativa & Cuantitativa: Evaluador para cada fuerza (Rivalidad, Clientes, Proveedores, Nuevos Entrantes, Sustitutos) con selección de presión [Baja/Media/Alta], factores determinantes e impacto directo en márgenes.

Tablero de Control y Simulador: Visualiza la intensidad mediante un Gráfico Radar, mide la Atractividad Global de la Industria y permite activar iniciativas estratégicas de Porter (Diferenciación, Liderazgo en Costes, Integración Vertical, Lock-in) observando el impacto dinámico en márgenes y reducción de presiones.

Síntesis e Informe Ejecutivo: Genera la matriz resumen completa y recomendaciones accionables lista para exportar o imprimir (Ctrl + P / Botón Imprimir).
